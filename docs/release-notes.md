## Brick'it Up v0.11.0

Télécharge l'APK ci-dessous et ouvre-le : il s'installe par-dessus la version précédente, ta partie est conservée. La version web (https://nanou974.github.io/Brick-it-Up/) se met à jour toute seule.

- **QR code de sauvegarde** : dans Paramètres → Code de sauvegarde, ta partie s'affiche aussi en QR code.
- Sur l'autre appareil, touche **SCANNER UN QR CODE** : la caméra s'ouvre, vise le QR code, et la partie est proposée au chargement (il faut confirmer).
- Avec l'appareil photo normal du téléphone, le QR code ouvre la version web, qui propose aussi de charger la partie.
- L'application demande l'accès à la caméra la première fois que tu scannes.
