## Brick'it Up v0.5.5

Télécharge l'APK ci-dessous et ouvre-le : il s'installe par-dessus la version précédente, ta partie est conservée.

- **Plus de demi-tours pendant les tapes rapides** : quand on tapotait vite (surtout avec deux doigts), la vue pouvait tourner d'un coup d'environ 180°. Maintenant :
  - seul le doigt qui commence le geste peut tourner la vue, un deuxième doigt annule la rotation ;
  - il faut glisser franchement (plus de 15 px) pour que la vue tourne ;
  - pendant une série de tapes rapides, la rotation est bloquée ; elle revient après une petite pause.
