## Brick'it Up v0.11.1

Télécharge l'APK ci-dessous et ouvre-le : il s'installe par-dessus la version précédente, ta partie est conservée. La version web (https://nanou974.github.io/Brick-it-Up/) se met à jour toute seule.

- **QR code beaucoup plus simple** : la sauvegarde ne garde que l'essentiel, le code passe d'environ 400 à moins de 100 caractères et le QR code a 4 fois moins de cases. Il se scanne même avec une caméra moyenne.
- Rien n'est perdu : niveau, éléments posés, étoiles, pièces, améliorations, boutique, camions, tenues et décors.
- Les anciens codes restent acceptés.
